# BoardView & NoteCard Features

This document details the functional capabilities of the main interactive board canvas and the NoteCard components.

## 📝 NoteCard Functions
NoteCards are the atomic units of collaboration within a board.

### 1. Content & Formatting
- **Rich Text / Markdown**: Supports formatted text with a dynamic textarea.
- **Attachments**: Users can upload files or link external URLs.
- **Image Support**: Direct embedding of images within notes.
- **Color Coding**: Notes can be categorized by color (e.g., Pink, Blue, Yellow, Green, Purple).

### 2. Interaction Features
- **Real-time Drag & Drop**: Notes can be moved around the canvas with instant synchronization for all users.
- **Pinning**: Teachers can pin important notes to prevent them from being moved or to highlight them.
- **Likes & Reactions**: Users can "like" notes; total counts are synced in real-time.
- **Comments**: Each note has a dedicated threaded comment section for deep-dive discussions.

### 3. Management
- **Note Menu**: Actions for duplicating, deleting, changing color, and toggling visibility.
- **Timestamping**: Tracks creation and last update times for every note.

## 🎨 BoardView Canvas Features
The container that orchestrates the collaboration.

### 1. Layouts
- **Grid Layout**: Auto-organizes notes into a clean, responsive grid.
- **Sandbox (Freeform)**: Allows users to place notes anywhere (X, Y coordinates), ideal for mind-mapping.
- **List Layout**: A vertical stream of notes, best for chronological reading.

### 2. Toolbar & Controls
- **Global Search**: Filter notes on the board by keyword.
- **Theme Switching**: Toggle between Light and Dark modes for the specific board.
- **Backgrounds**: Customizable board backgrounds (solid colors or images).
- **Format Toggle**: Switch between Standard, Quiz, and Assessment modes.

### 3. Security & Access
- **Draft Mode**: Boards can be hidden from students while being built.
- **Public/Private**: Control whether the board is accessible via a direct link or restricted to class members.
- **Copy/Paste Protection**: Security settings to prevent unauthorized content extraction.
